# منصة سجايا الرقمية

منصة لإدارة مبادرة «سجايا»: تسجيل الجمعيات، المراحل، الوثائق والشواهد، التقييم، اللقاءات، الإشعارات، والتقارير.

- `index.html` — الواجهة الرئيسية العامة
- `app.html` — المنصة (الإدارة / لجنة التقييم / الجمعيات)، توجيه بالـ hash
- `assets/js/store.js` — طبقة البيانات (حاليًا localStorage ببيانات تجريبية؛ مصممة لتُستبدل بقاعدة بيانات سحابية مثل Supabase)
- `assets/js/views-*.js` — الشاشات حسب الدور

تشغيل محلي:

```bash
python3 -m http.server 8783 --directory ~/sajaya
```

ثم افتح http://localhost:8783 — الدخول السريع للأدوار الأربعة متاح في صفحة الدخول، والتبديل بين الأدوار من أعلى الصفحة.
